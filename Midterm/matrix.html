Sorting Instructions

  • Mouse Drag: Drag a column header up/down to sort rows, or a row header left/right to sort columns. Pulling a selected column in the direction it sorts a tiny bit will deselect the column or row.
  • Region Select: Drag across cells to select a region; while it is outlined, the arrow keys and A / D sort only inside it. Clicking a single cell or off the table removes the highlight but keeps the outline and sorted values. Selecting a new region or pulling a header restores the old region's values.
  • Arrow Keys: Up/Down sorts all columns independently; Left/Right sorts all rows independently. After clicking the table, the arrow keys no longer scroll the page until you click off it.
  • A / D Keys: Sorts the entire matrix globally, or just the selected region (Ascending / Descending).
  • Escape Key: First removes the region's highlight, then restores the region's values and removes its outline, then resets the matrix to its original random state.
